# Sparkle - AI Video Template Creator Platform

一个现代化的AI视频模板创作者平台官网首页。

## 功能特性

- 🎨 现代化设计风格
- 📱 响应式布局，支持移动端
- 🎯 明星创作者展示卡片
- 🎬 视频模板分类展示
- 💰 创作者收益统计
- 🎪 渐变色彩设计

## 页面结构

### 头部区域
- 平台Logo和导航菜单
- 渐变背景设计

### 英雄区域
- 平台名称：Sparkle (32px, bold)
- 副标题：Video effect & template creator platform
- 副标题2：Create and earn
- CTA按钮：Sign up for the program
- 靠左对齐，64px margin

### 主要内容区域
- **左侧**：明星创作者个人卡片
  - 创作者头像
  - 昵称：@CreativeMaster
  - 擅长领域标签：Dance, Creative, Animal
  - 统计数据：
    - Total earning: $4,487.69
    - Today earning: $87.11
    - Effects created: 17

- **右侧**：视频模板分类展示
  - 分类：Dance, Funny, Beauty, Creative, Action, Transform
  - 每个分类显示4个视频卡片
  - 视频卡片比例：3:4

## 技术栈

- HTML5
- CSS3 (Grid, Flexbox, 渐变, 动画)
- 响应式设计
- Google Fonts (Inter)

## 使用方法

1. 下载或克隆项目文件
2. 在浏览器中打开 `index.html`
3. 或者使用本地服务器运行项目
